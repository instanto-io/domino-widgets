# PR tracking

This document tracks port-level fixes and their upstream status.

| Item | Description | Upstream PR | Status |
|---|---|---|---|
| `RecordDetailsCellInfo#getTargetRow` | Preserve the target row when rendering details so status edits in the details panel update the source row. | Not filed yet | Now included |

## Status meanings

- `Submitted upstream` — PR opened against upstream with a link in this row.
- `Accepted upstream` — upstream PR has been merged.
- `Now included` — fix currently implemented in this port only.
- `Not filed yet` — needs an upstream PR.
